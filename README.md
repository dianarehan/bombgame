# The Archivist's Legacy

**A Narrative-Driven Puzzle Game Prototype**

> "Welcome to the Syndicate, Victor. The office is ready for you... just as Volkov left it."

## 📖 Project Overview
This project is a 3D first-person narrative puzzle game developed in Unity. The player assumes the role of **Victor Rossi**, the successor to a mafia empire, who falls into a trap set by the antagonist **Silas Thorne**. The goal is to survive a "locked room" scenario by solving puzzles and disarming a Data Purge Device before it erases the Syndicate's history.

This prototype was created for **Assignment 3-4: Storyline, Narrative Level Design, and UI**.

* **Engine:** Unity 6
* **Genre:** Escape Room / Narrative Puzzle
* **Visual Style:** Gothic Revival & Vintage Noir

## 🎮 Gameplay & Features
* **3 Distinct Levels:**
    * **Prologue:** The Church (Narrative Trigger)
    * **Introduction:** The Hallway (Dialogue System)
    * **Main Game:** Volkov's Office (Puzzle Loop)
* **Interactive Narrative:** Environmental storytelling through audio logs, documents, and visual clues.
* **Puzzle Mechanics:** Point-and-click interaction system to examine objects, collect keys, and input codes.
* **UI System:** Diegetic timer, minimalist inventory, and subtitle system.

## 🕹️ Controls
* **Mouse Move:** Look around.
* **Left Click:** Interact with objects / Select inventory items.
* **Esc:** Pause Menu.
